# Impulse: финальная идентичность и внедрение в Client/Server

Дата: 2026-10-08. Владелец разрешил усилить сужение/слияние импульса и сразу адаптировать и внедрить финальный результат в оба проекта. Ранее действовавшее ожидание отдельной оценки для внедрения снято этим запросом.

## Финальный знак

- Основа V16/V17, общая геометрия сферы и линз сохраняется. Максимальное сужение середины — 26% относительно V16 вместо 12% в V17; оно плавно исчезает у концов. Наконечник остаётся исходным, белым и острым.
- Прозрачность середины усилить до 17%; исток мягче затухает в сфере. Усилить существующий свет в нижнем левом секторе, слегка расширить/осветлить свет истока. Не добавлять несогласованных наружных элементов.
- Основной фон — графит; прозрачный знак и кобальтовый вариант остаются в наборе. Все экспорты происходят из одной редактируемой SVG-модели.

## Client

- Заменить устаревшие launcher/round PNG, добавить adaptive icon с графитовым фоном, прозрачным foreground в безопасной зоне 66 dp из 108 dp, и монохромным слоем Android 13+.
- Подготовить согласованный статический VectorDrawable для системного splash, в пределах его круглой безопасной зоны. Gradients/masks сложного SVG не копировать в Android без поддержки: использовать проверенный растровый foreground для полной оптики, и адаптированные нативные векторы для splash/monochrome.
- Поставить общий знак в шапку Home; удалить старую неиспользуемую рисованную эмблему. Сохранить динамические цвета и функциональные криптографические иконки.
- Сохранить SVG-исходники, графитовый logo.png, README-шапку и социальную карточку в assets/brand, включить шапку в обе языковые версии README.

## Server

- Встроить многоразмерный ICO в Windows EXE через winresource; проверять наличие PE icon/group-icon ресурсов после сборки. Linux-пакетам добавить SVG/PNG и Terminal=true desktop entry.
- Добавить маленький цветной знак в уже существующую Info-панель TUI, не увеличивая её высоту и не уменьшая QR/логи. Не перекрывать адрес, счётчики и TTL; в узком режиме оставить полноценный логовый интерфейс.
- Сохранить общий SVG, графитовый logo.png, README-шапку и социальную карточку; включить шапку в обе языковые версии README. Дополнить упаковку файлов идентичности.

## Проверки и фиксация

1. Создать отдельные ветки в двух чистых репозиториях; криптографию, настройки с секретами, Wire v3 и версии не менять.
2. Проверить геометрию импульса, сферическую границу, адаптивные маски, монохром, PNG/ICO, схемы XML и ссылки на ресурсы. Визуально проверить основной знак и карточки.
3. Client: testDebugUnitTest, assembleDebug, lintDebug. Проверить ресурсы упакованного APK. Реальный запуск на устройстве — если устройство/эмулятор доступен; отсутствие отмечается явно.
4. Server: cargo build, cargo test, cargo clippy -- -D warnings. Сохранить TUI snapshot, проверить QR/данные и присутствие иконки в PE.
5. Обновить PROJECT.md и спецификации обоих репозиториев, создать атомарные Conventional Commits. GitHub-карточки и README внедряются в исходники; публикация релиза и удалённые настройки GitHub в запрос не входят.

## Источники платформенных правил

- https://developer.android.com/develop/ui/compose/system/icon_design_adaptive — слои 108 dp, безопасная зона 66 dp, monochrome.
- https://developer.android.com/develop/ui/views/launch/splash-screen — статический vector и круглая безопасная зона splash.
- https://docs.rs/winresource/0.1.31/winresource/ — компиляция и линковка Windows resource из build.rs.
