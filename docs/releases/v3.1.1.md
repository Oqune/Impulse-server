# Impulse Server v3.1.1

## English

Protocol v3 patch release. Protocol handler errors now close the offending session. Opening a bidirectional stream and completing authentication have absolute deadlines; authenticated sessions are not expired by the authentication deadline. Sync admission, backpressure and stream writes have bounded deadlines, and permits remain owned until write completion or drop. Shutdown reaches both network listeners.

Retained message storage is capped at 10,000 records and 64 MiB of opaque payloads with the existing 72-hour TTL. Sync snapshots use a fixed high-water mark, bounded 4 MiB/499-record pages and 16 operation/frame permits. Key replay caches are limited to 16 packets/64 KiB per session. Configuration rejects unsupported Argon2 PHC values and advertises the exact accepted tuple in the existing Protocol v3 field. Rust 1.88 is the minimum required by the locked dependency graph.

Local verification: 141 tests passed, two pre-existing client-only checks ignored; locked build, all-target Clippy and release build passed. A real authenticated QUIC connection remained active beyond the 30-second authentication deadline. Complete evidence and limitations are in `docs/audit/2026-10-14-defense-readiness.md`. The relay does not decrypt bodies, but sees external metadata. Hybrid post-quantum TLS negotiation and all cross-platform runtime behavior were not independently validated. Production readiness or certification is not claimed.

## Русский

Патч Protocol v3. Ошибка обработчика завершает сеанс. Открытие потока и аутентификация ограничены абсолютными сроками; успешно аутентифицированные соединения не закрываются по старому auth deadline. Sync и запись ответов ограничены временем и количеством одновременно удерживаемых страниц. Остановка достигает обоих слушателей.

Хранилище ограничено 10 000 сообщениями и 64 MiB зашифрованных payload с TTL 72 часа. Страницы Sync ограничены 4 MiB и 499 записями, доступны 16 разрешений. Кеш обмена ключами ограничен 16 пакетами и 64 KiB на сеанс. PHC проверяется до запуска, клиент получает точные допустимые параметры Argon2id. Минимальная версия Rust — 1.88.

Локально прошёл 141 тест, два прежних client-only теста пропущены явно; сборка, Clippy и release прошли. Результаты и ограничения отражены отдельно. Проект остаётся исследовательским прототипом.
