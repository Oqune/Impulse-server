# Impulse Server

WebSocket-чат сервер с аутентификацией и типизированным JSON-протоколом. Написан на Rust, использует bcrypt для хеширования паролей и tokio-tungstenite для WebSocket-соединений.

## Возможности

- Аутентификация по паролю (bcrypt)
- Рассылка сообщений всем подключенным клиентам
- Системные события подключения/отключения
- Ограничения на количество клиентов, размер сообщения и длину имени
- Санитизация имен пользователей
- Цветной вывод логов в терминал
- Опциональная поддержка TLS через feature flag

## Требования

- Rust 1.70+
- cargo

## Сборка

```bash
cargo build --release
```

## Запуск

```bash
# defaults: 0.0.0.0:8087, пароль из командной строки или дефолтный
./Impulse-server.exe

# кастомный host/port
./Impulse-server.exe --host 0.0.0.0 --port 9090

# кастомный пароль
./Impulse-server.exe -P my_secret_password

# без цветов (для cmd.exe)
./Impulse-server.exe --no-color
```

## CLI параметры

| Параметр | Short | Описание | Default |
|----------|-------|----------|---------|
| `--host` | | Адрес для прослушивания | `0.0.0.0` |
| `--port` | `-p` | Порт | `8087` |
| `--password` | `-P` | Пароль сервера | дефолтный, рекомендуется сменить |
| `--no-color` | | Отключить ANSI-цвета в выводе | false |
| `--help` | `-h` | Справка | |

## Безопасность

- Пароль обязателен для подключения
- Пароль хранится в хешированном виде (bcrypt)
- Максимум 100 одновременных клиентов
- Максимум 4096 байт на сообщение
- Имена пользователей санитизируются (контрольные символы удаляются, длина до 32 символов)
- Защита от переполнения счетчика client_id
- Ограниченный размер канала на клиент (16 сообщений) для backpressure

## Протокол

Все сообщения — JSON-объекты вида:

```json
{
  "v": 1,
  "ts": 1720000000000,
  "type": "...",
  ...
}
```

- `v` — версия протокола (сейчас `1`)
- `ts` — timestamp в миллисекундах
- `type` — тип сообщения

### Типы сообщений

#### Клиент → Сервер

**Аутентификация**
```json
{
  "v": 1,
  "ts": 1720000000000,
  "type": "auth",
  "name": "Oqune",
  "password": "secret"
}
```

**Чат**
```json
{
  "v": 1,
  "ts": 1720000000000,
  "type": "chat",
  "content": "привет"
}
```

#### Сервер → Клиент

**Результат аутентификации**
```json
{
  "v": 1,
  "ts": 1720000000000,
  "type": "auth_result",
  "success": true,
  "client_id": 1,
  "message": "Аутентификация успешна"
}
```

**Событие подключения/отключения**
```json
{
  "v": 1,
  "ts": 1720000000000,
  "type": "event",
  "event": "joined",
  "user_id": 1,
  "user_name": "Oqune"
}
```

**Чат-сообщение (рассылка)**
```json
{
  "v": 1,
  "ts": 1720000000000,
  "type": "chat",
  "content": "привет"
}
```

**Ошибка**
```json
{
  "v": 1,
  "ts": 1720000000000,
  "type": "error",
  "code": 401,
  "message": "Auth failed"
}
```
