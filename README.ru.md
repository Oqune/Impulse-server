## Обзор

Impulse — сервер ретрансляции для сквозь-шифрованного мессенджера. Сервер
**никогда не видит открытый текст**: клиенты шифруют полезную нагрузку
локально и отдают серверу только непрозрачные байты, порядковый id, метку
времени и публичный ключ сообщения. Сервер хранит сообщения в оперативной
памяти (TTL 72ч), присваивает монотонные id и рассылает их всем
подключённым клиентам.

Ключевые особенности:

- **Транспорт:** только WebTransport поверх QUIC (`wtransport` 0.7). TLS 1.3
  обязателен; старый WSS-транспорт удалён.
- **Бинарный протокол:** длино-префиксные бинарные кадры с опкодами `0x01`–`0x08`
  (little-endian), а не JSON.
- **Аутентификация:** клиент обязан отправить `Auth` с паролем; сервер
  проверяет SHA-256 хэш в постоянное время (constant-time).
- **TLS / Сертификаты:** самоподписанные сертификаты **Ed25519**, срок 14 дней,
  автоматическая ротация с **перекрытием 2 дня**. PEM-материал сохраняется в
  `--cert-dir` (относительно исполняемого файла, `0600` на Unix).
- **TOFU:** сервер выводит QR-код (правая панель TUI) с SHA-256 отпечатком
  DER-сертификата и временем выпуска. Клиенты сканируют его, фиксируют
  `serverCertificateHashes` и доверяют серверу при первом подключении. При
  ротации новый отпечаток рассылается через `NewCertHash` (0x07).
- **Хранилище:** кольцевой буфер в RAM, сообщения истекают через 72ч (TTL),
  ограничены количеством (`10_000`) и размером полезной нагрузки (`1 МБ`).
- **Ретрансляция:** рассылка всем активным сессиям; опоздавшие подключаются
  через `Sync { last_seen_id }`.
- **Администрирование:** **TUI** с тремя зонами:
  - **Шапка Server Info** (сверху слева): адрес привязки, транспорт
    (`WebTransport/QUIC TLS1.3 (h3)`), версия, число SAN, живые
    `сессии / MAX_SESSIONS`, число сообщений, TTL, макс. размер полезной
    нагрузки, короткий SHA-256 отпечаток сертификата, обратный отсчёт до
    истечения и индикатор ⚠ rotating во время перекрытия ключей.
  - **Логи** (снизу слева): поток логов сервера.
  - **Панель TOFU** (справа, при достаточной ширине терминала): QR-код с
    полным сгруппированным отпечатком сертификата, временем выпуска и
    оставшимся сроком.
  `Ctrl+C` или `q` — выход с корректным завершением.

## Сборка и запуск

```bash
cargo build --release
./target/release/Impulse-server --config config.toml
# или с флагами CLI (переопределяют config.toml):
./target/release/Impulse-server --port 4433 --cert-dir cert_data \
    --password-hash $(printf 'yourpassword' | sha256sum | cut -d' ' -f1)
```

| Флаг | Короткий | Описание | По умолчанию |
|------|----------|----------|---------------|
| `--host` | | Адрес привязки | `0.0.0.0` |
| `--port` | `-p` | Порт WebTransport (QUIC) | `4433` |
| `--cert-dir` | | Каталог для сертификата/ключа | `cert_data` |
| `--san` | | Дополнительный SAN (DNS или IP), повторяемый | _нет_ |
| `--password-hash` | | SHA-256 hex пароля (обязателен) | _нет_ |
| `--config` | | Путь к TOML-конфигу | `./config.toml` |

`password_hash` **обязателен** — небезопасного значения по умолчанию нет.
Сгенерировать: `printf 'pw' | sha256sum`.

## Платформы

Impulse-server написан на переносимом Rust (edition 2024) и собирается на
целях ниже при наличии рабочего Rust-тулчейна и UDP/QUIC-сети. CI собирает
релизные бинари для Linux/macOS/Windows на x86-64 и ARM64.

| Платформа | Target triple | Статус | Примечания |
|-----------|--------------|--------|------------|
| Linux (x86-64) | `x86_64-unknown-linux-gnu` | ✅ Проверено | Рекомендуется для серверов |
| Linux (ARM64) | `aarch64-unknown-linux-gnu` | ✅ CI | AWS Graviton, Raspberry Pi 4 (64-bit OS) |
| macOS (Apple Silicon) | `aarch64-apple-darwin` | ✅ CI | |
| macOS (Intel) | `x86_64-apple-darwin` | ✅ CI | |
| Windows (x86-64) | `x86_64-pc-windows-msvc` | ✅ Проверено | Консольное приложение; биндит UDP/QUIC порт напрямую |
| Windows (ARM64) | `aarch64-pc-windows-gnu` | ✅ CI | |
| FreeBSD / BSD | `x86_64-unknown-freebsd` | ⚠️ Только вручную | У `aws-lc-sys` (криптобэкенд) нет FreeBSD-sysroot под cross-тулзами; нужен нативный тулчейн FreeBSD |

Готовые бинари для каждой строки ✅ (кроме FreeBSD) прикрепляются к
соответствующему GitHub Release.

### Требования

- **Rust 1.85+** (edition 2024).
- Доступный **UDP-порт** (QUIC поверх UDP). Откройте/пробросьте порт в фаерволе.
- На **Unix** файл приватного ключа пишется с правами `0600` автоматически;
  на Windows ACL оставляется ОС.
- **Root/администратор не требуется** — биндите высокий порт (например `4433`)
  вместо `443`. QR/TOFU-сценарий позволяет доверять самоподписанному
  сертификату, публичный CA не нужен.

## Протокол (бинарный, little-endian)

Все кадры: `[opcode: u8][...поля]`. Блобы с длиной-префиксом — `u32 len`,
затем `len` байт.

| Опкод | Напр. | Имя | Поля |
|--------|-------|------|------|
| `0x01` | C→S | Auth | пароль (`len`-префикс, UTF-8) |
| `0x02` | S→C | AuthResult | `u8` статус (`0`=ok, `1`=fail) + опц. `len`-префикс сообщение |
| `0x03` | C→S | Sync | `u64` last_seen_id |
| `0x04` | S→C | SyncResponse | `u32` count, затем по сообщению: `u64 id`, `u64 ts`, `len`-префикс payload |
| `0x05` | C→S / S→C | Data | C→S: `len`-префикс payload. S→C: `u64 id`, `u64 ts`, `len`-префикс payload |
| `0x06` | оба | Heartbeat | `u64` client_timestamp (эхо-ответ) |
| `0x07` | S→C | NewCertHash | ровно 32 сырых SHA-256 байта + `u64` unix expiry |
| `0x08` | C→S / S→C | KeyExchange | `len`-префикс публичный ключ (ретранслируется другим) |

Неизвестные/невалидные опкоды от клиента закрывают соединение. Простаивающие
потоки закрываются через 300с. Сессии ограничены 1024; перегруженные
полезные нагрузки (>1 МБ) отбрасываются.

## Безопасность

- Обязательный QUIC/TLS 1.3 транспорт (WebTransport).
- Короткоживущие Ed25519-сертификаты (14д) с авто-ротацией (перекрытие 2д);
  новый сертификат применяется к **живому** TLS-резолверу (без рестарта) и
  анонсируется через `NewCertHash`.
- Закрепление отпечатка TOFU через QR-код + `NewCertHash`.
- Эфемерное хранилище только в RAM, TTL 72ч, ограниченный кольцевой буфер и
  размер полезной нагрузки.
- Сравнение хэша пароля в постоянное время (constant-time).
- Файл приватного ключа ограничен `0600` на Unix.
- Открытый текст, пароли и полезные нагрузки не логируются.

## Корректное завершение

`Ctrl+C` / `SIGTERM` (или `q` в TUI) запускает корректное завершение:
эндпоинт перестаёт принимать новые сессии, активные записи дренируются.
Логи также пишутся в `logs/impulse-server.log`.

## Структура проекта

```
src/
  cert.rs      — генерация Ed25519-сертификата, ротация, SHA-256 TOFU-отпечаток, FS-persist
  storage.rs   — эфемерный RAM-лог сообщений (TTL 72ч, sequence id)
  protocol.rs  — бинарные кадры (опкоды 0x01–0x08)
  server.rs    — WebTransport-эндпоинт, обработка сессий, broadcast-ретрансляция
  tui.rs       — терминальный UI: шапка Server Info, лог-поток, TOFU QR / панель отпечатка
  logging.rs   — мост tracing → TUI / файл
  config.rs    — загрузка CLI + config.toml
  lib.rs       — связывание + run()
  main.rs      — точка входа бинаря
  tests.rs     — юнит-тесты (protocol + storage)
```
