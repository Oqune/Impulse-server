## Обзор

Impulse — сервер ретрансляции для сквозь-шифрованного мессенджера. Сервер
**никогда не видит открытый текст**: клиенты шифруют полезную нагрузку
локально и отдают серверу только непрозрачные байты, порядковый id, публичный
ключ Ed25519 отправителя и метку времени. Сервер хранит сообщения в оперативной
памяти (TTL 72ч), присваивает монотонные id и рассылает их всем подключённым
клиентам.

Ключевые особенности:

- **Транспорт:** только WebTransport поверх QUIC (`wtransport`). Старый WSS
  транспорт полностью удалён.
- **TLS / Сертификаты:** самоподписанные сертификаты **Ed25519**, срок 14 дней,
  автоматическая ротация с **перекрытием 2 дня**. PEM-материал сохраняется в
  `--cert-dir` (относительно исполняемого файла).
- **TOFU:** сервер выводит QR-код (нижняя панель TUI) с SHA-256 отпечатком
  DER-сертификата и временем выпуска. Клиенты сканируют его, фиксируют
  `serverCertificateHashes` и доверяют серверу при первом подключении.
- **Хранилище:** кольцевой буфер в RAM, сообщения истекают через 72ч. Каждое
  сообщение: `u64` id, публичный ключ отправителя, зашифрованная полезная
  нагрузка, метка времени.
- **Ретрансляция:** рассылка всем активным сессиям; опоздавшие подключаются
  через `sync { last_seen_id }`.
- **Администрирование:** двухпанельный **TUI** (логи сверху, QR + отпечаток +
  таймер ротации снизу). Веб-интерфейса нет. `Ctrl+C` или `q` — выход.

## Запуск

```bash
cargo build --release
./target/release/Impulse-server --port 4433 --cert-dir cert_data
```

| Флаг | Короткий | Описание | По умолчанию |
|------|----------|----------|---------------|
| `--host` | | Адрес привязки | `0.0.0.0` |
| `--port` | `-p` | Порт WebTransport (QUIC) | `4433` |
| `--cert-dir` | | Каталог для сертификата/ключа (относительно исполняемого файла) | `cert_data` |
| `--san` | | Дополнительный SAN (DNS или IP), повторяемый | _нет_ |

При первом запуске генерируется пара Ed25519-сертификат/ключ и записываются
`impulse_cert.pem` и `impulse_key.pem` в `--cert-dir`.

## TOFU / Доверие серверу

Самоподписанный сертификат шифрует трафик, но клиенты не доверяют ему по
умолчанию. Impulse использует **доверие при первом использовании**:

1. При запуске TUI показывает QR-код с `impulse-tofu|<sha256>|<issued_at>`.
2. Клиент сканирует код, извлекает отпечаток и фиксирует его как ожидаемое
   значение `serverCertificateHashes`.
3. При первом подключении клиент проверяет, что SHA-256 предъявленного
   сертификата совпадает с закреплённым отпечатком.

Перекрытие ротации в 2 дня сохраняет предыдущий отпечаток действительным во
время перехода, поэтому закреплённые клиенты не прерываются.

## Протокол

Все кадры — JSON, разделённый переводом строки, передаются по двунаправленному
потоку WebTransport.

| Тип | Направление | Поля |
|-----|-------------|------|
| `sync` | клиент → сервер | `last_seen_id: u64` — повторить сообщения с `id > last_seen_id` |
| `message` | оба | `id`, `sender_pubkey`, `payload` (base64-шифр), `timestamp` |
| `error` | сервер → клиент | `code`, `message` |

Сервер назначает `id` и `timestamp` самостоятельно; клиентские значения
игнорируются.

## Безопасность

- Обязательный QUIC/TLS транспорт (WebTransport).
- Короткоживущие Ed25519-сертификаты (14д) с авто-ротацией (перекрытие 2д).
- Закрепление отпечатка TOFU через QR-код.
- Эфемерное хранилище только в RAM, TTL 72ч, ограниченный кольцевой буфер.
- Лимит полезной нагрузки (1 МБ).
- Без паролей и аккаунтов — анонимность по замыслу.
